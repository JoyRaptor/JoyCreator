## What this is

**Joy Creator** is a complete creative studio for Android phones: JoyBrush (draw, paint, animate),
Studio (video editing with layers, masks, keyframes, effects, transcription), VisLab (music visuals),
SpriteLab and Avatar (characters and puppets), Capture (recording), and Joybot, the AI helper that knows
all of it. It began as a fork of FadCam (a GPL-3 screen recorder) and is moving to stand fully on its own.

**The promise that never moves:** free forever, unhobbled. No ads, no subscription, no watermark, no
export paywall. AI is bring-your-own-key at zero margin.

## The one epistemic rule

**A checkbox is a wish. A commit is a fact. A screenshot is proof.**
This repo's documents have been confidently wrong in both directions. When a document and the code
disagree, the code wins; when the code and the phone disagree, the phone wins. Check a document's date
before you trust it.
