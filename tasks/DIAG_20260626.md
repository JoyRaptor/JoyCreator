## User design intent (2026-06-26, authoritative)
- Captions are PER-LAYER: every video clip AND every audio clip owns its own caption box
  (independent style, position, keyframed/static/hidden). NOT a single global caption.
- This loop region: show AUDIO[1]'s captions only (CLIP[6] captions stay OFF).
- Vision: two videos on one timeline => two independent caption boxes (debates/conversation/music).
  Tapping a caption selects that layer and opens ITS transcript box in the editor.
- Future maybe: an opt-in "universal caption layer" that unifies all captions underneath. Not now.
- SOURCE OF TRUTH: make EXPORT match PREVIEW exactly (position, which layers, hidden windows, timing).
- Feature request (later, not a bug): caption dialog gets a COPY icon (dark gray, always shown) and a
  PASTE icon (white, only visible when a caption was copied). Paste applies the copied caption's full
  style+position+settings to the current layer's caption. Lets you reuse a hand-tuned caption box.
