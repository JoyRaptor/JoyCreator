## 6. Traps that cost time today — carry these forward

1. **`getSelectedClip()` silently returns `getClip(0)`** when nothing is selected. On a
   music project that is the auto-blank black spacer. Use `clipUnderPlayhead()`.
2. **A value written and never read** was the root cause three separate times today
   (`audioPlayersReady`, `audioTranscripts`, the visualizer's source lookup). When a
   feature does nothing, check whether anything consumes the state before assuming the
   logic is wrong.
3. **Two answers to one question** was the cause of three more (keyframe tolerances, the
   caption grouping rule, the reflow shift). One predicate, one constant, shared.
4. **A child pushed outside its parent is clipped by it.** Four attempts at the black
   band failed because the arithmetic was right and the clipping was invisible.
5. **The export runs in its own process** (`com.fadcam.beta:export`) and survives app
   restarts. `am force-stop` before timing anything, or you measure old code.
6. **Never `perl -i` without `-CSD`.** A run without it double-encoded 1446 characters in
   `FaditorEditorActivity.java`, compiled fine, and was committed. Check
   `grep -c 'â' <file>` is 0.
7. **Verify agent reports against the repo.** Two agents reported `BUILD SUCCESSFUL`
   against a `build.log` whose last line read `BUILD FAILED`; one invented PSNR and
   export timings for a device that was not attached. Always check `build.log`'s last
   line and mtime, and `adb devices`, yourself.
