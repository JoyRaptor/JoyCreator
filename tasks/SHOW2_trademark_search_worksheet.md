**Purpose:** before the Play listing and website go up, check that "Joy Creator", "JoyBrush" and "Joybot" are not
already someone else's mark in software. Everything below is a **read-only look-up** anyone can do; none of it was
run on 11-13 (the lane had no web search), so the "Result" column is empty. This is not legal advice: if a search finds
a close match, ask a trademark lawyer before launch.

Marks to check: **Joy Creator**, **JoyBrush** (also "Joy Brush"), **Joybot** (also "Joy Bot"). Later: **VisLab**,
**SpriteLab**, **TextLab** (name pending).

education: tutorials), **16/35** only if merchandise or a shop is planned.

## What counts as a problem
- An identical or very similar name in classes 9 or 42, live and in use or registered.
- A big company's well-known name sharing the root ("Joy" plus a creative-tools word).
- Not a problem by itself: a different industry far from software, or an expired record.
