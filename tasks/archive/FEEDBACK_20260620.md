## FILTERS
- [x] **CRITICAL FIXED + DEVICE-VERIFIED: parameters now work.** Root cause: Media3
  `ExoPlayer.setVideoEffects` does NOT render in this preview path (the app already uses View
  transforms for rotate/crop for the same reason). Fix: the `player_view` is a **TextureView**
  (`surface_type="texture_view"`), so a View-level `android.graphics.RenderEffect` grades the video in
  real time. `FaditorEditorActivity.applyPreviewColorGrade(clip)` builds a `ColorMatrix` from
  exposure/contrast/saturation/temperature/tint and sets `playerView.setRenderEffect(...)`; wired into
  selection/advance/load + the filter sheet callback. Removed the dead `setVideoEffects` path.
  **Verified: dragging Saturation to 0 turns the preview grayscale live.** (API 31+; older devices keep
  an ungraded preview — export unaffected.)
  - ⚠️ **Remaining:** highlights/shadows/fade/vignette/grain are shader-only and NOT in the preview
    matrix yet (they still bake on EXPORT). TODO: add a `RuntimeShader` (AGSL, API 33+) RenderEffect
    for the full grade so those preview too. The 5 matrix params (the most-used) preview now.
- [x] **No dim — DONE + verified** (`dialog.getWindow().setDimAmount(0f)`; video stays bright behind).
- [x] **Max ~1/3 height, doesn't cover video — DONE + verified** (sheet height fixed to screenH/3,
  peek=expanded). This also **fixes the scroll-eats-top / drag-past-fullscreen bug** (panel can't expand
