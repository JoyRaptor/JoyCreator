# Avatar Studio X6: the second audit (2026-11-28)

**Auditor:** Claude, the X2/X3 session (Opus 5.5), the lead's go 11-28 (Codex is gone; X6 moved to Claude).
**Base:** `joy-creator` at `875dc1c28`.

**Method.** Five independent read-only reviews, one per area, each told to confirm every finding by reading the code
path end to end:

- the room activity and Perform UI;
- the build-side UI;
- `perform` / `file` / `intake`;
- `face` / `scene` and the scene UI;
- a fresh-eyes review of the auditor's own X2/X3/slice 2 code (`solve`, `draw`, `studio` and the three Studio draw sites).

Each finding carries a mark:

- ✔ checked again by the auditor in the code before it was written here;
- ◐ the reviewer confirmed it end to end, not yet re-checked by the auditor;
- ? plausible only.

Fixes are made by the owning session, or by the auditor once that session says go in `tasks/avatar/CHANNEL.md`.
Every fix comes with a test that fails before it.

**Owners:**
- R, B, P: slice 1, the room (`AvatarRoomActivity`, `ui/`, `perform/`, `file/`, `intake/`).
- S: slice 3, scenes (`scene/`, `ui/Scene*`).
- F: the face session (`face/`).
- M: the auditor (`solve/`, `draw/`, `studio/`, the three draw sites, the hand code in `Inputs`).

Status column:
- *fixed* = landed with its test;
- *asked* = waiting on the owner;
- *open* = not yet taken.
