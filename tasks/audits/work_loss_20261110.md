# Work-loss hunt, 2026-11-10

By Claude Fable 5.2, for the owner. Job card: [SAFE-1](../jobs/SAFE-1_work_loss.md). Started from
`origin/joy-creator` at `4e55ba4c7`; branch `claude/workloss-20261110`.

**How it was done.** Three read-only agents listed every place each wing writes, deletes, moves or loads
something a person made (their lists are facts with file and line, not verdicts). I then read the save paths
themselves end to end and confirmed each finding below in the current code. A finding I did not confirm
myself says so.

**What "fixed" means here.** The code is written, the app builds, and a test that fails on the old code
passes on the new. It does **not** mean tried on a phone unless the Phone column says so.
