# Part D: what Video Studio already does, and what the room takes from it

Part of the [Avatar Studio phone spec](AVA_PHONE_SPEC.md). Written 2026-11-23 from the Android source at `cece72679`.
**The owner's rule:** "does Video Studio already do this, and does it do it well? If yes plug it in. If not, fix it there and
then use it." So every item is one of: ✅ **plug in** (as it is) · 🔧 **fix there first** (in Studio, proven in Studio, then
used here) · 🆕 **new** (Studio has nothing).
`F` = `app/src/main/java/com/fadcam/ui/faditor`, `S` = `studiokit/src/main/java/com/fadcam/ui/faditor`.
Method names and lines were read by an agent and spot-checked by me (the recorder's rate, the palette values, the 30 fps
export, the class files existing); line numbers move, so search by name.

## The fix-there-first list, in the order the slices need it

1. `VoiceoverRecorder` sample listener and level (slice 1, recording with lip-sync).
2. Studio's Undo / Redo hover labels name the step (slice 1).
3. `transcriptDrawerShiftPx` moved into `DrawerPlace` (slice 3, the strip).
4. `ExportSheetParts` lifted out of the editor (slice 2).
5. `SpriteOverlayItem` character reference + `CharacterItemPuppet` dispatch in `CompositeExportOverlay` / `SpriteBlendGlEffect`, after a word in the STU-7 channel (slice 2).
6. A Solid colour clip in Studio (slice 2, for the key colour; the PNG stopgap is the fallback).
7. `PuppetPalette` reads `Studio` (any time; small).

Each is proven in Studio first: its own Studio test suite (`cloud-build.ps1 test <branch> studio`), and a before/after
screenshot of the Studio screen it touches.
