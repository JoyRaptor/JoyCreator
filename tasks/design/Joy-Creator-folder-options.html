Folders you earn

The app starts with an empty Joy Creator folder and never makes a folder in advance. Your work goes at the top. A folder appears when you make one, or when you say yes to a suggestion once things pile up. A screen-recording-only user never sees a Recordings folder. A painter never sees Exports.

Rule 1

Anything that belongs to a piece of work goes wherever that work lives. Share-ins while a project is open, its exports, and its gathered files all follow the project file. A project at the top means the top. A project in Client A/ means Client A/.

Rule 2

Anything that belongs to no work goes to its folder if you have one, otherwise the top. Share-ins with nothing open go to Assets/ if it exists. Recordings go to Recordings/ if it exists. Otherwise both go to the top.

Rule 3

Nothing breaks when you move things. The app keeps track of every file by its contents, not only its path. Move, rename or rearrange in any file manager and every project still finds its files. That's what lets you organize however you want.

Supplies: the things you make art with

The built-in brushes, papers and fonts live inside the app, so they add no files. When you make, import or want to edit one, a copy lands here, in a folder named for its kind. Each kind folder appears only once you have one of that kind.

One brush is one readable file. The pictures it needs sit beside it and start with the same name, so they sort together: Soft pencil.brush.json, Soft pencil.grain.png, Soft pencil.tip.png. Open the JSON in any text editor and change it.

A set of brushes is a folder. A downloaded set stays together, like Inky set/. The app also accepts one folder per brush, so nothing anyone shares gets refused.

Plugins are always a folder each. They're bundles with their own pieces.

Want fonts or brushes at the top? Drag the folder out. Rule 3 means the app still finds it.

Your picks

Ideas that need no extra folders

  • Exports beside their work

    Lecture 3.mp4 sits next to Lecture 3.joyproject. Sort by name and each project lines up with everything it made. Sort by type and all the videos group together.

  • Every kind of file has its own ending

    .joybrush, .brush.json, .palette.json, .sprite.json. Sorting by type stays clean even in one flat folder, which is what lets the folder count stay this low.

  • Dates written year, month, day

    Screen recording 2026-10-13 14.32.mp4. Name order is then time order, without a "by date" folder.

  • The gallery sorts; the folders don't have to

    Inside the app you get views like "by wing", "this week", "used in Lecture 3". They are views of the same files, so none of them adds a folder.

  • Make a box whenever you want one

    The app reads the whole folder. Make Client A/ or Dinosaur series/ anywhere and it keeps working. The structure is a starting point you're free to rearrange.

How people with many moving parts organize

What each approach contributes, and the one this page leaves out.

Your own work at the top

Steph Ango, CEO of Obsidian

Keeps his own notes in the vault's root, with only a few support folders (Attachments, Clippings, References). He avoids nesting because one note often belongs to several areas.

Your work goes at the top. Side folders only for support material.

First-order retrievability

Adam Savage, maker

The things you use most should be reachable without moving anything else out of the way. His tool carts are built around it.

Nothing you use often sits more than one folder deep.

Always Be Knolling

Tom Sachs, sculptor

Lay like things out side by side so you can see everything at once and spot what's missing.

One ending per kind, so "sort by type" works like knolling.

A box per project

Twyla Tharp, choreographer

Every dance starts with a labelled box that gathers everything that fed it. Movin' Out filled twelve boxes.

"A box per project" is a choice in the builder, and anyone can make boxes later.

Sort by how active it is

Tiago Forte, PARA

Projects, Areas, Resources, Archives, running from active to dormant. Finished things move out of sight but stay kept.

An optional Archive folder.

Start simple, earn structure

Nick Milo, ACE for Obsidian

Atlas, Calendar, Efforts. His advice is to start with the defaults and only customize once real use shows the need.

Ship few folders. Let people add their own.

One inbox, emptied later

David Allen, Getting Things Done

Everything new lands in one place first and gets sorted when you have a moment.

An optional Inbox for things shared in.

Mise en place

Professional kitchens

Ingredients are prepped and within reach before cooking starts, kept apart from finished plates.

"What goes in" kept apart from "what comes out", and the kitchen names.

Bins by media type

Film editors

Footage, Audio, Music, Graphics, Exports. It's familiar, but it breaks when a PDF, a script or a brush file arrives. That's the problem you raised with "Media".

The in / out split, without sorting by media type.

Stacks, one level deep

Procreate

The gallery groups drawings into stacks, and a stack can't hold another stack. People find things because it never gets deep.

The app's gallery stays one level deep too.

Numbered everything

Johnny.Decimal

Areas, categories and IDs like 15.52 Trip to NYC. It's powerful for paperwork.

Left out: it's the code-number feel you don't want. Its one useful lesson, fewer and broader categories, is already here.
