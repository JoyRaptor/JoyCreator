## How to work here (learned the hard way)
- **Never commit from the main folder** `C:\+Projects\Screenrecorder\FadCam`. It is stale and full of CRLF-noise "modified"
  files. Work in worktrees off `origin/joy-creator`; I used `C:/Temp/jb-merge` (detached, for merges and docs),
  `C:/Temp/jb-lead` (feature branches) and `C:/Temp/jb-240`. Copy `local.properties` into any new worktree.
- **Builds** (one at a time machine-wide):
  `powershell -File <scratchpad>\lead-build.ps1 -Dir <worktree> -Log <log> -Tasks "<gradle tasks>"`.
  The script is in this session's scratchpad. Recreate it if it's gone: take `jb-gradle.lock` with CreateNew, set
  `JAVA_TOOL_OPTIONS=-Djdk.net.unixdomain.tmpdir=C:\Windows\Temp`, run `gradlew.bat --offline --no-watch-fs <tasks>`,
  delete the lock in finally. The PC has 16 GB and is often under 2 GB free.
- **Tests:** `-p joybrush :core:jvmTest :androidkit:test --continue`, then `:joybrush-android:testDebugUnitTest :app:assembleDefaultDebug`.
  Count results from the XML in `build/test-results`. Last full green: core 1903, androidkit 373, joybrush-android 115.
- **Phones.** adb is at `%LOCALAPPDATA%\Android\Sdk\platform-tools\adb.exe` and is not on PATH.
  - Note 9 sandbox: USB, serial = SANDBOX_SERIAL in `tools/devices.local.sh` (gitignored), Android 10, 1080×2220 @ 60 Hz. The performance floor.
  - Note 20: wireless, owner's real projects; `bash tools/wifi-adb.sh`. Its wireless debugging switches itself off.
  - Install with `install -r -d app/build/outputs/apk/default/debug/app-default-arm64-v8a-debug.apk`, only when
    `dumpsys window | grep mCurrentFocus` shows the launcher. Never uninstall.
- **Bench** (debug builds only):
  `adb shell am start -n com.fadcam.beta/com.fadcam.joybrush.JoyBrushBenchActivity --es jb_bench "scribble,spiral" --es jb_bench_brushes "media:wet:Round,..." --ei jb_bench_runs 3 [--ez jb_media_legacy true]`
  - Results: `adb logcat -s JoyBrushPerf`. Runner script: `scratchpad\run-bench.ps1`. The code is
    `androidkit/bench/*` and `joybrush-android/bench/BenchRunner.kt`.
  - It opens a fresh drawing that is never saved, then closes itself.
- **Merges:** test the branch, then fast-forward or merge into `origin/joy-creator` from `C:/Temp/jb-merge`. Never resolve a
  conflict in the owner's folder.
