## Result and scope

The document format advances to version 10. A PAINT cel can retain editable records, ordered pixel slabs and saved
looks; frozen brush definitions travel with the drawing. StrokeCodec writes version 3 and reads genuine versions 1/2,
assigning old records their file order. Sequence, lock and group fields round-trip. Old INK metadata migrates to PAINT;
the archive can freeze validated library copies through an explicit resolver. Slab filenames handle the full nonnegative
Long sequence range and reject overflow. Every declared slab must supply bytes before composition.

Saving validates both directions of every archive payload and performs all checks before writing stream bytes. Current
raster screens and recovery refuse line/slab/look payloads and frozen brush metadata before reconstructing or replacing
content. Raster exports refuse unsupported artwork, including hidden/noncurrent cels, before allocation, paper/stroke
callbacks, output, animation sinks or cache creation. An unused frozen brush list alone does not change exported pixels
and is permitted by exports. Legacy INK callback rendering remains supported by the standalone renderer.

These refusals are deliberate until slices d/f bind live replay and composition. Production screen/recovery paths do not
yet supply the legacy resolver: legacy lines are not claimed to open in the live screen. No engine, Activity, paper/brush
algorithm, shader or device change is included. Pure pixel/media payloads keep their existing representation.

## Next live-binding gates

Bind record capture after guide snapping and before brush response, retaining the actual live seed and unpredicted samples.
Keep ordered slabs, GPU replay, saved look caches, erasure and one-history Undo in the same cel transaction. Do not enable
the screen capability until opening, editing, recovery and save retain all payloads.

Record IDs are unique within a cel, not across a drawing. Layer/frame cloning preserves them. The current Select host's
string-ID replacement API therefore needs an explicit cel/layer address contract before all-layer live edits; a globally
unique-ID assumption would address the wrong line. Successful lifted-pixel commits must rebase pixels and transformed
coverage at identity for the next gesture/fill. Failed commits preserve the previous lift and support preview rollback.
