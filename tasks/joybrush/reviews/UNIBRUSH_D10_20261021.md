# D10 — bounded large-circle optimization verified; performance acceptance incomplete

The production vertex shader tightens only canonical, fully soft Gaussian circular Unibrush dabs
with resolved radius256–2048, effective scale1 or0.5, no sampled tip, taper, anchor, aspect,
profile blend or expanding minimum size. It retains the historical extent everywhere else.
Dab placement, flow, RNG, cap accumulation and legacy recipes are unchanged.

The portable GPU harness runs the actual production stamp, MRT cap/RGB-moment accumulation and
commit shaders against a SHA-locked historical vertex shader. Final report:174 cases,110 eligible,
174 nonempty, zero failed. Eligible pixels differ by at most one RGBA8 level; excluded cases and
batch-versus-single VBO transport are exact. All four deliberately broken controls are detected.
The suite includes radius boundaries, subpixel positions, scale extremes, negative tile origins,
32/64 overlapping low-flow deposits, min-size/profile/image/dual exclusions and final commit.
Raw evidence: UNIBRUSH_D10_GPU_20261021.json. These PC SwiftShader RGBA8 results do not certify
phone R16F/RGBA16F, half-resolution quality or frame rate.

Run with Node and Playwright Core available:
`node joybrush/tools/unibrush_d10/tight_circle_check.js --diagnose`
The script uses installed Edge by default; CHROME can name another Chromium executable.
NODE_PATH can locate an existing Playwright Core installation. It installs no dependencies.

Debug benchmark helpers support an explicit nominal stamp size without mutating saved presets,
and scoped refusal observation that preserves the previous callback and detects replacement.
Their four tests pass. The held BenchRunner patch reports resolved recipe JSON/hash, nominal size,
flow, spacing and refusal status. A timeout, no stroke frames or lost observer makes a run
inconclusive. Contact timing is explicitly labelled; lift-to-final publication remains unmeasured.
