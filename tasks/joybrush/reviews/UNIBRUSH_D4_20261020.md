# Unibrush D4: deterministic colour and replay

Engine verified on codex/unibrush (2026-10-20), ready for Lead review. This is not app or phone acceptance.

The new nullable `color.dynamics` is explicit opt-in (brush v15). Dormant imported/stored legacy
ColorJitter values retain their historical fixed-colour rendering. New modes are perDab,
perStroke and perStrokeDrift, with hue/saturation/value ranges, secondary mix and pressure hue.
Colour uses independently salted random channels, preserving legacy placement, size, angle
and scatter. Drift smoothly interpolates indexed distance knots, with bounded O(1) work after
arbitrary distance jumps. Pressure hue remains live in every mode.

Primary and secondary colours freeze at contact. Raw recording codec v5 adds an optional
secondary ARGB field; old versions retain an explicit white secondary fallback. Replay runs
the same response, smoothing, placement, colour and scatter pipeline. Changing a palette or
rebrushing reruns the seeded dynamics instead of modifying already mixed pixels.

The original scalar stroke mask remains authoritative for opacity. Colour accumulates separate
RGB moments with the SAME decay: `m'=rgb*cap*d+m*(1-d)`. Commit uses `m*k` for RGB and the
original mask times k for alpha. Moment alpha is only the blend factor and cannot replace the
mask when pressure changes its cap. Normal, erase, multiply and screen retain their existing
whole-stroke compositing. CPU painters allocate moments only when an explicit colour appears,
seeding a previous fixed-colour prefix correctly. Legacy strokes retain their old path.

The original 17n-float instance prefix remains unchanged. An optional 4n-float RGB/enabled tail
follows the previous optional fade and quad tails. Attribute12 is reset after drawing; null
entries use the frozen fixed colour. The production shader writes a separate MRT moment
attachment. Companion tile ownership is transactional and bounded; clear deletes current names,
context loss abandons dead names, and byte/name inventories include companions.

Production GPU proof (RGBA8, headless Edge/SwiftShader): 32 commit cases across two backdrops,
two opacity scales, four blends and two layer opacities; maximum error .0019607843 (<2/255).
Accumulation max error .0016941177. MRT and separate attachments match byte-for-byte. A complete
17n+2n+12n+4n VBO matches three individual draws byte-for-byte and an independent attribute
oracle. Wrong offset differs in 48 bytes; wrong blending in 80; wrong alpha/selector each fail
24 cases. Historical 820c62802 shaders match current legacy pixels exactly; existing order and
scale controls still detect their deliberate faults.

Full core: 2577 tests, zero failures/errors, four existing optional corpus skips. Full Android backend: 1059 tests, zero failures/errors/skips. Serialized offline run completed in 8m24s.

Lead-owned engine/View/inventory adapters are supplied only as `patches/UNIBRUSH_D4_LEAD.patch`.
`git apply --check` passes against this branch's base files. The patch freezes palette context,
uploads fixed RGB, adds moment attachments/commit bindings, accounts/releases resources, and
converts resolved per-dab colour to gray for masks AFTER dynamics. It has not been applied,
compiled as a combined app, merged or tested on a phone. Lead must reconcile it against current
main and rerun combined acceptance. No media or Lead source files were edited.

Whole-stroke line shaping with new tip/colour fields remains refused until D7 forwards those
fields. Raw-sample editable replay is tested separately. SVG outline export explicitly requests
image export for unsupported styled/coloured tips instead of silently exporting a flat fill.
